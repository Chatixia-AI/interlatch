- **You hear when the hub stops taking your sends:** when the hub turns this computer's token away, or can't be reached
  for two hours, a warning appears on Home, in the Hub card under **Settings › Devices**, in the status bar, in the
  menu-bar icon and in `interlatch hub status`. Before, only the log said so, and the dashboard kept showing "Connected".
  To fix a rejected token, paste a new invite code into **Join again**. With `[updates] notify` on, a desktop
  notification also tells you, once each time sends start failing
  ([Troubleshooting](docs/troubleshooting.md#a-hub)).
