- **Hark:** the browser extension saves your [Hark](https://hark.com) chats as you use hark.com, one session per chat
  per day, with the tools Hark used. With the Hark Mac app installed, **Sources › Web chats › Hark** and Home's Agents
  card show whether it runs and whether its link to this Mac works, from the app's log ([Hark](docs/sources.md#hark)).
  The extension needs version 1.2.0.
